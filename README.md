# 🐄 Dairy Farm Management System

A modern full-stack Dairy Farm Management System built with **React**, **TypeScript**, **Tailwind CSS**, and **Supabase** to simplify dairy farm operations through an intuitive dashboard.

## ✨ Features

- 🐄 Animal Management
- 🥛 Daily Milk Production Tracking
- 👥 Customer Management
- 💰 Sales Management
- 👨‍🌾 Employee Management
- 💉 Health & Vaccination Records
- 🐮 Breeding Management
- 💸 Expense Tracking
- 📊 Dashboard Analytics
- 🔐 Secure Authentication (Supabase Auth)
- ☁️ Cloud Database (Supabase PostgreSQL)
- 📱 Responsive Design

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/saranrajx31/dairyfarm.git
```

### Navigate to the project

```bash
cd dairyfarm
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file and add:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Run the development server

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
